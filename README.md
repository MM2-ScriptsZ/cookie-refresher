# 💀 Roblox Cookie Refresher

**One-click tool that KILLS your old cookie and generates a BRAND NEW one instantly!**

## 🎯 What it does

- ✅ Verifies your current cookie
- 💀 **KILLS the old cookie instantly** (logs out from all devices)
- ✨ Generates a brand new cookie
- 🔄 Old cookie will NEVER work again

## 🚀 Deployment

### Deploy to Vercel (Recommended)

1. Push this code to GitHub
2. Go to [vercel.com](https://vercel.com)
3. Import your repository
4. Deploy!

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone)

## 📝 Usage

1. Open your deployed app
2. Paste your current `.ROBLOSECURITY` cookie
3. Click **"REFRESH & KILL OLD COOKIE"**
4. Copy the NEW cookie
5. **Your old cookie is now DEAD**

## ⚠️ Important

- The old cookie you paste will be **permanently killed**
- You MUST save the new cookie
- Old cookie will NOT work anymore

## 🔒 Security

- No webhooks
- No cookie theft
- Direct Roblox API only
- Optional database logging
